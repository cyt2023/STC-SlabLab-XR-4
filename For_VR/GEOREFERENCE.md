# For_VR geographic rendering contract

## Source and method ledger

| Layer | Role | Source / method | Coordinate reference | Units | Update policy |
|---|---|---|---|---|---|
| Prediction HS / Water Level | inferred model field | local paired HDF5 event files | EPSG:4326 | m | regenerate with `tools/convert_for_vr_to_unity.py` when HDF5 changes |
| Ground Truth HS / Water Level | measured/reference field | local paired HDF5 event files | EPSG:4326 | m | same as above |
| Surface topology | measured source geometry | 7,364 supplied nodes and 13,445 supplied faces | EPSG:4326 | degrees | shared by all variables and hours |
| Hong Kong basemap | contextual, not analytical data | cached OpenStreetMap snapshot generated by `tools/generate_hong_kong_basemap.py` | Web Mercator | map coordinates | static local fallback; attribution remains visible |
| Height exaggeration | display encoding | Unity runtime | projected map space | display-only | fixed per physical channel |

The primary Unity renderer reads `UnityRaw/GeoSurface` and renders the original
unstructured mesh directly. The 96 x 64 raster files remain a compatibility
fallback and are not the preferred geographic surface.

## Coordinate contract

- Input longitude/latitude order: `[longitude, latitude]`.
- Input bounds: `113.650220–114.659994 E`, `22.0300455–22.6998139 N`.
- Longitude increases left to right; latitude increases from the near/south edge
  to the far/north edge.
- The basemap and every data vertex use the same Web Mercator transform and the
  same bounding box. No longitude wrapping is allowed for this fixed extent.
- Face indices remain the supplied 0-based topology. The renderer changes only
  triangle winding to make normals point upward in Unity X/Z space.
- Prediction and Ground Truth share one fixed color/height range per physical
  channel, so switching datasets does not change the meaning of a color.
- HS uses a sequential scale. Water Level uses a zero-centred diverging scale;
  signed height is a display exaggeration around a visible baseline.
- Zero in the compatibility raster means outside the mesh. The preferred mesh
  keeps original node values as little-endian `float32`; color is only a visual
  encoding and is not used as the numeric source for frame statistics.

## Time and vertical conventions

- Playback labels use the supplied `time_hkt` values (UTC+08:00). Event gaps are
  discontinuities and must not be described as uninterrupted hourly history.
- Both channels are in metres.
- The Water Level source does not identify its vertical datum as HKPD, Chart
  Datum, or another named datum. The UI must therefore say `Water Level (m)` and
  must not invent a datum label.

## Alignment checks

- Binary contract: 7,364 coordinate pairs, 13,445 valid faces, and 672 node-value
  frames for each of four datasets.
- Bounds check: binary coordinate extrema agree with the conversion manifest.
- Orientation check: southwest and northeast corners map to the corresponding
  basemap corners.
- Coastline check: all 1,397 boundary edges were projected onto the cached map;
  they follow the Hong Kong, Shenzhen Bay, island and eastern coastline geometry.
